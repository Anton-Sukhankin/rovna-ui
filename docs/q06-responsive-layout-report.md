# QG-06: Responsive, layout и текст

## Итог

Группа `QG-06` завершена 8 августа 2026 года. Специализированный Playwright-runner `scripts/audit-storybook-responsive-layout.js` проверил Tier 1, overlays, узкие таблицы, zoom 200%, уменьшенную высоту мобильного viewport и стрессовые текстовые данные.

## Матрица

| Категория | Проверок | Результат |
| --- | ---: | --- |
| Viewport: 10 Tier 1 stories x 5 профилей | `50` | `50/50` |
| Zoom 200% | `10` | `10/10` |
| Stress states | `9` | `9/9` |
| Всего | `69` | `69/69` |

Поддерживаемые профили: `360x800`, `390x844`, `768x1024`, `1440x900`, `1920x1080`. Уменьшенный `360x480` используется для проверки доступности действий при экранной клавиатуре; это симуляция уменьшения visual viewport, а не управление реальной OS-клавиатурой.

## Проверяемые риски

- горизонтальное переполнение документа и Storybook canvas;
- clipping dialog/drawer и недоступные fixed actions;
- наложение labels, текста, кнопок и overlays;
- portal positioning у краев viewport;
- таблица и toolbar на мобильной ширине;
- Modal, Drawer, Select и Popover на мобильном viewport;
- длинный русский текст, непрерывный ID и intentional ellipsis;
- zoom 200% без потери интерактивных действий;
- Storybook error screens, page errors и failed resources.

В ходе проверки найдено сжатие HotFilters: текст «Админ» становился вертикальным на мобильной ширине. Контейнер переведен в переносимую строку, а дочерние filters ограничены `max-width: 100%`; повторный полный прогон прошел без `crampedHotFilters`.

## Русская языковая логика

Для `declOfNum` добавлен отдельный unit-контракт с числами `0`, `1`, `2`, `5`, `11`, `21`, `22`, `25` и `-2`. Результат: `9/9` tests passed. Длинные сообщения ошибок и непрерывные идентификаторы дополнительно проверены responsive/visual stress-сценариями.
