# Storybook Language Policy

Updated: 2026-07-31.

## Primary Language

Основной язык Rovna UI и демонстрационных примеров Storybook - русский (`ru`).

Русский язык обязателен для пользовательского текста:

- подписей кнопок, полей, переключателей и пунктов меню;
- заголовков, описаний, подсказок и сообщений;
- демонстрационных данных таблиц, списков, фильтров и форм;
- текстов состояний загрузки, успеха, предупреждения и ошибки.

## Technical Exceptions

Английский сохраняется там, где он является частью технического контракта или проверяемого сценария:

- имена компонентов, props, variants и Storybook story identifiers;
- package names, imports, URL и программные значения;
- форматы файлов, grid-маркеры наподобие `col-6`, email и названия брендов;
- отдельные stories, которые явно проверяют английскую локаль, например `Internationalization` с `lang='en'`.

Эти исключения не меняют основной язык Storybook: глобальная locale по умолчанию остается `ru`.

## Automated Gate

Проверка запускается из `app/`:

```bash
yarn storybook:language:check
```

Эквивалентная команда без Yarn:

```bash
node scripts/check-storybook-language.js
```

Gate анализирует все `*.stories.*` и проверяет пользовательские поля, JSX-текст, массивы опций, тексты уведомлений и динамически генерируемые демонстрационные данные. Проверка также блокирует прямой вывод системных логических значений через `toString()` вместо понятных русских состояний. Команда включена в DS-only quality gate и public GitHub Actions workflow.
