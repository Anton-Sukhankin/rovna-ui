# Subagent Example: Button Story Correction

This is a routing example, not an active backlog item.

## Objective

Correct one user-facing Russian label in the `@rovna-ui/primitives` Button story without changing Button runtime behavior.

## Current State

The target story has one confirmed label that does not follow the Russian primary-language policy. Runtime source behavior is otherwise unchanged.

## Target State

The exact story renders the corrected Russian label, the language check remains green and no unrelated snapshots or components change.

## Fact Owner

- User-facing story text: target `Button.stories.tsx`.
- Current component route: generated Button passport and catalog entry.
- Language policy: `docs/storybook-language-policy.md`.

## Read Scope

- `AGENTS.md`
- `app/AGENTS.md`
- `docs/agent-context/import-rules.md`
- `docs/agent-context/component-passports/generated/tend-ui-primitives-button.md`
- `app/packages/tend-ui-primitives/package.json`
- `app/packages/tend-ui-primitives/src/Button/Button.stories.tsx`
- `app/packages/tend-ui-primitives/src/Button/Button.tsx`

## Write Scope

- `app/packages/tend-ui-primitives/src/Button/Button.stories.tsx`

## Prohibited Paths And Actions

- Do not read or change S-Tracker, history, another package or generated catalog output.
- Do not change Button runtime props or package exports.
- Do not install dependencies or update snapshots for a text-only story correction unless a focused check proves that update necessary.

## Generated-File Rule

No generated file is edited directly. Regenerate documentation only if the story title, ID or exported state changes.

## Acceptance Commands

```text
corepack yarn storybook:language:check
corepack yarn test:storybook
corepack yarn lint
```

## Expected Report

Report the changed story, the original and corrected label, exact command results and confirmation that runtime source remained untouched.

## Escalation Condition

Stop when the label is generated by runtime localization rather than the story, when another package owns the text or when the required write lies outside the declared story file.
