# @rovna-ui/rollup-config

Базовый конфиг `rollup` от которого наследуется каждый пакет

> Важно! Пакет `@rovna-ui/rollup-config` создан для нужд команды дизайн-системы.

# Установка

```sh
yarn add @rovna-ui/rollup-config@latest
```

# Использование

```jsx
const config = require('@rovna-ui/rollup-config');
```
