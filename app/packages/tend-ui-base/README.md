# @rovna-ui/base

Библиотека содержит базовые компоненты, которые не вошли в дизайн-систему, но часто появляются в сложных компонентах

> Важно! Пакет `@rovna-ui/base` создан для нужд команды дизайн-системы.

# Установка

```sh
yarn add @rovna-ui/base@latest
```

# Использование

```jsx
import { Button, Input } from '@rovna-ui/base';
```
