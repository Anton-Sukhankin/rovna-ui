# Tooltip

## Описание

Tooltip (всплывающая подсказка) - это окно сообщения, которое отображается, когда пользователь наводит курсор на элемент пользовательского интерфейса или фокусирует его. Подсказка должна быть сопряжена с интерактивным элементом пользовательского интерфейса, таким как кнопка. Всплывающие подсказки следует использовать экономно и содержать краткую дополнительную информацию.
Хотя всплывающие подсказки могут использоваться для создания интерактивных элементов, таких как кнопки и ссылки, не включайте эти элементы во всплывающие подсказки и вместо этого используйте Popover.

## Использование

```tsx
import { Tooltip } from '@rovna-ui/primitives';
```

### Для лучшего `tree-shaking`

```tsx
import { Tooltip } from '@rovna-ui/primitives/Tooltip';
```
