# Хлебные крошки

`Breadcrumbs` показывает положение текущей страницы в иерархии продукта и
позволяет вернуться на любой родительский уровень.

## Использование

```tsx
import { Breadcrumbs } from '@rovna-ui/components/primitives';

<Breadcrumbs
  items={[
    { key: 'home', label: 'Главная', href: '/' },
    { key: 'projects', label: 'Проекты', href: '/projects' },
    { key: 'current', label: 'Карточка проекта' },
  ]}
/>
```

Прямой импорт:

```tsx
import { Breadcrumbs } from '@rovna-ui/components/primitives/Breadcrumbs';
```

Также доступен низкоуровневый пакет:

```tsx
import { Breadcrumbs } from '@rovna-ui/primitives/Breadcrumbs';
```

## Правила использования

- Передавайте уровни от корня к текущей странице.
- Последний элемент считается текущей страницей, не является ссылкой и получает
  `aria-current="page"`.
- Используйте короткие и однозначные подписи. Полный строковый текст остается
  доступен в подсказке при визуальном сокращении.
- Для длинной иерархии задавайте `maxItems`. Компонент сохраняет первый и последние
  уровни, а скрытую середину раскрывает по кнопке с троеточием.
- Для навигации через роутер можно передать `href` и перехватить переход в
  `onClick`, либо передать только `onClick`. Во втором случае уровень будет
  семантической кнопкой.
- Уточняйте `aria-label`, если на странице больше одной цепочки навигации.
- Не используйте хлебные крошки вместо истории посещений, шагов процесса или
  основного меню продукта.

## Состояния

Компонент покрывает цепочки из одного, двух и множества уровней, сокращенное и
раскрытое состояния, иконки, другой разделитель, длинные подписи, управление с
клавиатуры и узкий экран. Состояния загрузки, ошибки и отключения к хлебным
крошкам не применяются.
