# Как загрузить новый логотип в `cdn`?

1. Получаем исходник `svg` файла от дизайнера
2. Переименовываем его в нижний регистр
3. Кладем его в `src/logos`
4. Комитим изменения

```sh
git commit -m 'feat: add `SKek` logotype'
```

6. Пушим в `main` ветку
7. Выполняем команду

```
yarn menu
```

8. Выбираем команду "Выгрузить статику в cdn"
9. Пушим созданный тег, пушим `main` ветку,
10. Ждем обновления кеша в `cdn`
