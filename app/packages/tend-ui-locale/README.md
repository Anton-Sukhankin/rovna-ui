# @rovna-ui/locale

Библиотека содержит базовые текста и сообщения в двух языках

> Важно! Пакет `@rovna-ui/locale` создан для нужд команды дизайн-системы. Также, для корректного отображения текстов в компонентах дизайн-системы на продукте копия `@rovna-ui/locale` должна быть одна

# Установка

```sh
yarn add @rovna-ui/locale@latest
```

# Использование

```jsx
import { useTranslation } from '@rovna-ui/locale';
```
