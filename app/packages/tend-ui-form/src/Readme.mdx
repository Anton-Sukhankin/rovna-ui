# Основные отличия от `Form` из `antd`

- Вся логика инкапсулирована от `React` в отдельном `js` классе. Все сообщение со стейтом происходит через паттерн `Observer` и `useSyncExternalStorage`
- Более прозрачная и упрощенная верстка
- `onChange` принимает только 1 параметр
- Добавлен функционал `controlled` режима через свойство `values`
- Добавлен функционал `disabling` полей в зависимости от заполнения конкретных полей формы через поля `requires`
- Метод формы `form.setFields` может принимать как новый стейт, так и `callback`функцию, в параметры которой передается предыдущее состояние
- При передачи в метод `form.setFields` нового значения, внутреннее состояние формы будет **полностью** обновлено. (В формах `antd` непереданные поля брались из предыдущего состояние)

# FormInstance

Все ниже приведенные методы являются **императивными**. Это значит, что они не будут триггерить вызовы `onChange` и `onSubmit`

```ts
interface FormInstance<State extends object = object> {
  /**
   * Сброс поля по ключу
   */
  resetField(name: string | string[]): void;
  /**
   * Сброс всех полей
   */
  resetFields(): void;
  /**
   * Установка поля по ключу
   */
  setField(name: string | string[], payload: Any): void;
  /**
   * Установка всех полей
   */
  setFields(payload: State | ((previous: State) => State)): void;
  /**
   * Получить поле по ключу
   */
  getField(name: string | string[]): Any;
  /**
   * Получить все поля
   */
  getFields(): State;
  /**
   * Запустить валидацию поля по ключу
   */
  validateField(name: string | string[], payload: Any): Promise<void>;
  /**
   * Запустить валидацию всей формы
   */
  validateFields(): Promise<State>;
  getFieldErrors(name: string | string[]): ValidationResult[] | null;
  getFieldsErrors(): ValidationResult[];
  /**
   * Submit формы
   */
  submit(): Promise<State>;
}
```

# useForm

Основной `hook` для работы с формой. На вход принимает `parameters` в качестве `UseFormParameters<S>`

```tsx
const form = useForm(parameters);
```

## UseFormParameters

```tsx
interface UseFormParameters<S extends object = object> {
  /**
   * Значения формы
   */
  values?: S;
  /**
   * Значения по умолчанию
   */
  defaultValues?: S;
  /**
   * `Callback` функция, вызываемая при вводе значений
   * @param changed Частичный слепок стейта формы с затронутыми полями
   * @param state Новое состояние стейта формы
   */
  onChange?: (changed: Partial<S>, state: S) => void;
  /**
   * `Callback` функция, вызываемая при срабатывании `submit` события формы
   */
  onSubmit?: (state: S) => void;
}
```

# useWatch

```ts
/**
 * Позволяет подписываться на изменение состояния полей формы.
 * Изменение полей, не перечисленных в `extractor` не триггерит реренер компонентаю
 * @param form - Сущность, возвращаемый хуком `useForm`
 * @param extractor - Строка, массив строк или callback-функция
 */
const value = useWatch(form, extractor);
```

Хук позволяет подписываться на изменение полей формы. В качестве первого аргумента принимает `instance` формы, возвращаемый из `useForm`. Второй аргумент может быть `string`, `string[]`, `callback`.
