# @rovna-ui/fonts

Основной набор шрифтов `10d` и `ДИТ`

# Установка

```sh
yarn add @rovna-ui/fonts@latest
```

# Использование

```jsx
import ReactDOM from 'react-dom';
import { MuseoSansCyrl } from '@rovna-ui/fonts';

ReactDOM.render(
  <React.Strict>
    <RovnaUI>
      <MuseoSansCyrl />
      ...
    </RovnaUI>
  </React.Strict>,
);
```
