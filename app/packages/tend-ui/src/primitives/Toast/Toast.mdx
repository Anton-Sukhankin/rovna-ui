# Toast

## Описание

Компонент Toast используется для динамических уведомлений.
Toast - это немодальные элементы окна, зависящие от времени, используемые для отображения коротких сообщений. Обычно они появляются в верхней части экрана и исчезают через 5 секунд.

## Использование

Статичное

```tsx
import { Toast } from '@rovna-ui/components/primitives';
import { RovnaUI } from '@rovna-ui/components/theme';

Toast.init();
RovnaUI.init();

ReactDOM.render(
  <React.Strict>
    <RovnaUI>
      <Toast.Styles />
      ...
    </RovnaUI>
  </React.Strict>,
);
```

Через `hook`

```tsx
import { Toast } from '@rovna-ui/components/primitives';

const MyComponent = () => {
  const [methods] = Toast.useToast();
  return (
    <Button
      onClick={() => {
        methods.success({
          message: 'Success',
          description: 'Hello World',
        });
      }}
    >
      Success
    </Button>
  );
};

ReactDOM.render(
  <React.Strict>
    <RovnaUI>
      <Toast.Styles />
      <MyComponent />
    </RovnaUI>
  </React.Strict>,
);
```
