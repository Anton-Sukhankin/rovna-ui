# Accordion

## Описание

Accordion - обеспечивает размещение большого объема контента в небольшом пространстве за счет раскрытия. Заголовок дает пользователю высокоуровневый обзор содержимого, позволяя пользователю решать, какие разделы читать.

`Accordion` могут сделать обработку информации и поиск более эффективными. Однако он скрывает контент от пользователей, и важно учитывать, что пользователь не замечает или не читает весь контент. Если пользователю, скорее всего, нужно прочитает весь контент, то не используйте аккордеон, поскольку это увеличивает нагрузку создавая дополнительный клик; вместо этого используйте страницу с полной прокруткой и обычными заголовками.

## Использование

```tsx
import { Accordion } from '@rovna-ui/components/primitives';
```

### Для лучшего `tree-shaking`

```tsx
import { Accordion } from '@rovna-ui/components/primitives/Accordion';
```
