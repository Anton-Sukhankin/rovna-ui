# Dialog

## Описание

Компонент Dialog используется для динамических уведомлений.
Dialog - это немодальные элементы окна, зависящие от времени, используемые для отображения коротких сообщений. Обычно они появляются в верхней части экрана и исчезают через 5 секунд.

## Использование

Статичное

```tsx
import { Dialog } from '@rovna-ui/components/primitives';
import { RovnaUI } from '@rovna-ui/components/theme';

RovnaUI.init();

const MyComponent = () => {
  return (
    <Button
      onClick={() => {
        Dialog.success({
          message: 'Заголовок в одну или несколько строк',
          content: 'Текст модального окна в одну или несколько строк',
        });
      }}
    >
      Success
    </Button>
  );
};

ReactDOM.render(
  <React.Strict>
    <RovnaUI>
      <Dialog.Styles />
      <MyComponent />
      ...
    </RovnaUI>
  </React.Strict>,
);
```

Через `hook`

```tsx
import { Dialog } from '@rovna-ui/components/primitives';

const MyComponent = () => {
  const [methods] = Dialog.useDialog();
  return (
    <Button
      onClick={() => {
        methods.success({
          message: 'Заголовок в одну или несколько строк',
          content: 'Текст модального окна в одну или несколько строк',
        });
      }}
    >
      Success
    </Button>
  );
};

ReactDOM.render(
  <React.Strict>
    <RovnaUI>
      <Dialog.Styles />
      <MyComponent />
    </RovnaUI>
  </React.Strict>,
);
```
