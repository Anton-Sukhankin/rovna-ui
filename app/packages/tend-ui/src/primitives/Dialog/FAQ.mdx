# FAQ

### Как разделить логику нажатия на крестик и логику нажатия на кнопку "Отмена"?

```tsx
const instance = Dialog.confirm({
  cancelButtonProps: {
    onClick: () => {
      // логика при нажатии на  кнопку "Отмена"
      instance.destroy(); // если нужно по нажатию "Отмена" также закрывать модальное окно
    },
  },
  onCancel: () => {
    // логика при нажатии на крестик
    instance.destroy();
  },
});
```
