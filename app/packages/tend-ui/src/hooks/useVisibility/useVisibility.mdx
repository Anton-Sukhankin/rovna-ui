# useVisibility

## Использование

```tsx
import { useVisibility } from '@rovna-ui/components/hooks';
```

### Для лучшего `tree-shaking`

```tsx
import { useVisibility } from '@rovna-ui/components/hooks/useVisibility';
```

```js
const visibility = useVisibility();
visibility.visible; // true/false
visibility.show();
visibility.hide();
visibility.toggle();
```
