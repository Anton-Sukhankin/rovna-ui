# FAQ

### Я прокидываю кастомный контент в ячейки таблицы в заголовках с помощью свойства `title`, но при этом этот же кастомный контент появляется в списке в боковом меню фильтров. Что делать?

Свойство `title` устарело и не рекомендовано к использованию. Используйте дополнительно свойство `label` в конфиге настроек колонок. Оно имеет более высокий приоритет

```tsx
const column: ColumnConfig = {
  label: 'Подрядчик',
};
```
