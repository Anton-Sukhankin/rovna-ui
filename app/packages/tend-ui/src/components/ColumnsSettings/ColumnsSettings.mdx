# ColumnsSettings

> Компонент устарел и больше не поддерживается. Используйте компонент из пакета `@rovna-ui/columns-settings`

[Документация](/docs/Rovna UI/Columns Settings-drawercolumnssettings--docs) |
[Миграция](/docs/Rovna UI/Columns Settings-%D0%BC%D0%B8%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F--docs)

## Использование

## 3.3.0

```tsx
import { Table } from '@rovna-internal/components/primitives';
import { ColumnsSettings, useColumnsSettings } from '@rovna-ui/components/components';
import { useVisibility } from '@rovna-ui/components/hooks';

const visibility = useVisibility();
const { columns, properties } = useColumnsSettings([{ key: '1', title: 'Title' }]);

<Button onClick={visibility.show}>
  Open
</Button>
<Table columns={columns} />
<ColumnsSettings
  {...properties}
  open={visibility.visible}
  onClose={visibility.hide}
/>;
```

## Интерфейсы

```ts
type ColumnConfig = {
  /**
   * Уникальный ключ колонки
   */
  id: string;
  /**
   * @deprecated Use `label` instead
   */
  title?: React.ReactNode;
  /**
   * Label в списке
   */
  label?: string;
  /**
   * Видимость
   * @default true
   */
  visible?: boolean;
  /**
   * Можно ли колонку скрыть
   * @default  false
   */
  disabled?: boolean;
  /**
   * Закрепление
   * @default true
   */
  pinnable?: boolean;
  /**
   * Можно ли колонку переместить
   * @default true
   */
  draggable?: boolean;
  /**
   * Позиция закрепления
   * @default undefined
   */
  fixed?: 'left' | 'right';
};
```
