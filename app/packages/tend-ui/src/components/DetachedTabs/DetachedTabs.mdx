# DetachedTabs

> Компонент не рекомендуется к использованию. Если вам необходимо использовать `Tabs` в `Drawer` используйте композитный `Drawer` из пакета `@rovna-ui/primitives`

## Использование

```tsx
import { DetachedTabs } from '@rovna-ui/components/components';
```

### Для лучшего `tree-shaking`

```tsx
import { Root, Buttons, Children } from '@rovna-ui/components/components/DetachedTabs';
```
