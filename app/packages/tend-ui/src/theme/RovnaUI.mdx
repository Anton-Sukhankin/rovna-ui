# RovnaUI

## Использование

```tsx
import { RovnaUI } from '@rovna-ui/components/theme';
```

### Для лучшего `tree-shaking`

```tsx
import { RovnaUI } from '@rovna-ui/components/theme/RovnaUI';
```

## Переопределение клиента для защищенных URL

```tsx
import axios from 'axios';

const client = axios.create();

const App = () => {
  return <RovnaUI client={client}>...</RovnaUI>;
};
```
