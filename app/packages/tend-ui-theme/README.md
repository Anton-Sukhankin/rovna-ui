# @rovna-ui/theme

Библиотека содержит базовые компоненты для работы с темой

> Важно! Пакет `@rovna-ui/theme` создан для нужд команды дизайн-системы. Также, для корректного отображения cnbktq в компонентах дизайн-системы на продукте копия `@rovna-ui/theme` должна быть одна

# Установка

```sh
yarn add @rovna-ui/theme@latest
```

# Использование

```jsx
import { RovnaUI } from '@rovna-ui/theme';
```
