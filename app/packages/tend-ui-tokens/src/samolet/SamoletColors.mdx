# Цветовая палитра продуктов 10D

## Использование

```tsx
import { colors } from '@rovna-ui/tokens/samolet';
import { useColors } from '@rovna-ui/components/theme';
```

## Для лучшего `tree-shaking`

```tsx
import { colors } from '@rovna-ui/tokens/samolet/colors';
import { useColors } from '@rovna-ui/components/theme';
```
