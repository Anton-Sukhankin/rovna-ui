# @rovna-ui/tokens

Цветовая палитра `10d` и глобальных продуктов

# Установка

```sh
yarn add @rovna-ui/tokens@latest
```

# Использование

```jsx
import { colors as samolet } from '@rovna-ui/tokens/samolet';
import { colors as global } from '@rovna-ui/tokens/global';

// CSS переменные
import '@rovna-ui/tokens/samolet/colors.css';
import '@rovna-ui/tokens/global/colors.css';
```
