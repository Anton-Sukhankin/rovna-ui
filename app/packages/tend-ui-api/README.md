# @rovna-ui/api

Библиотека содержит необходимые хуки и клиенты для работы с `http` запросами

> Важно! Пакет `@rovna-ui/api` создан для нужд команды дизайн-системы. Также, для корректной работы запросов в компонентах дизайн-системы на продукте копия `@rovna-ui/api` должна быть одна

# Установка

```sh
yarn add @rovna-ui/api@latest
```

# Использование

```jsx
import { useApi } from '@rovna-ui/api';
```
