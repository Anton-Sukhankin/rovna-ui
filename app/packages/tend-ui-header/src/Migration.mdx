# Миграция

## С шапки `samolet-ui`

1. Убедиться в том, что корневой элемент приложения имеет селектор `id="root"`

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>S.Blueprint</title>
  </head>
  <body>
    <!-- Корневой div должен иметь id="root" -->
    <div id="root"></div>
  </body>
</html>
```

2. Удалить глобальные стили `samolet-ui` если они имееются

```tsx
// Удаляем
import 'samolet-ui/lib/theme/global.css';
```

3. Удалить `ВСЕ` глобальные стили для `html`, `body` и `root` в проекте если они имееются

4. Установить зависимости

```sh
yarn add @rovna-ui/primitives@latest
yarn add @rovna-ui/header@latest
```

5. Обернуть приложение в `Layout`

> Важно! `Layout.Root` должен быть единственным и первым корневым элементом всего приложения, возвращающий `DOM` узел. Компоненты, создающие контекст-провайдеры не в счет, они допускаются

```tsx
import { Layout } from '@rovna-ui/primitives';
import { SamoletHeader } from '@rovna-ui/header';

const App = () => {
  return (
    <RovnaUI>
      <Layout.Root>
        <SamoletHeader />
        <Layout.Main>
          <Layout.Title>Заголовок</Layout.Title>
          Контент
        </Layout.Main>
      </Layout.Root>
    </RovnaUI>
  );
};
```

6. Импортировать `Normalize` из пакета `@rovna-ui/styling`

```tsx
import { Layout } from '@rovna-ui/primitives';
import { SamoletHeader } from '@rovna-ui/header';
import { Normalize } from '@rovna-ui/styling';

const App = () => {
  return (
    <RovnaUI>
      <Normalize />
      <Layout.Root>
        <SamoletHeader />
        <Layout.Main>
          <Layout.Title>Заголовок</Layout.Title>
          Контент
        </Layout.Main>
      </Layout.Root>
    </RovnaUI>
  );
};
```

7. Для корректной работы бургер-меню нужно:

- подключить [`samolet-oauth2`](/bu_moscow/10d/common/samolet-oauth2)
- передать свой `axios` клиент в `RovnaUI`

```tsx
import { Layout } from '@rovna-ui/primitives';
import { SamoletHeader } from '@rovna-ui/header';
import { Normalize } from '@rovna-ui/styling';
import axios from 'axios';

// Ваш http клиент с прикрученной авториацией
const client = axios.create();

const App = () => {
  return (
    /* передаем клиент */
    <RovnaUI client={client}>
      <Normalize />
      <Layout.Root>
        <SamoletHeader />
        <Layout.Main>
          <Layout.Title>Заголовок</Layout.Title>
          Контент
        </Layout.Main>
      </Layout.Root>
    </RovnaUI>
  );
};
```

## С `@rovna-ui/header@1.x.x` на `@rovna-ui/header@2.x.x`

```tsx
import { Layout } from '@rovna-ui/primitives';
// import { Header } from '@rovna-ui/header'; // версия @rovna-ui/header@1.x.x
import { SamoletHeader } from '@rovna-ui/header'; // версия @rovna-ui/header@2.x.x
import { Normalize } from '@rovna-ui/styling';

const App = () => {
  return (
    /* передаем клиент */
    <RovnaUI>
      <Normalize />
      <Layout.Root>
        <SamoletHeader />
        <Layout.Main>
          <Layout.Title>Заголовок</Layout.Title>
          Контент
        </Layout.Main>
      </Layout.Root>
    </RovnaUI>
  );
};
```
