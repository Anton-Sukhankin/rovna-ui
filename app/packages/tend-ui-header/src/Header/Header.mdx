# Header

Шапка для полной кастомизации или использования на продуктах для внешнего рынка.

## Использование

```tsx
import { Header } from '@rovna-ui/header';
```

## API интеграция

`Header` имеет встроенную поддержку API через внутренние хуки `useBurgerProps` и `useSupportProps`.

Эти хуки автоматически вызываются внутри компонента `Header`.

### useBurgerProps

Хук встроен в `Header` и автоматически получает данные бургер-меню из API:

**Endpoint:** `GET /api/product_b2b/`

**Возвращаемые данные:**

- `items` - массив элементов меню
- `loading` - состояние загрузки
- `error` - ошибка запроса
- `moduleOptions` - опции модулей для формы поддержки
- `onOpenChange` - обработчик открытия бургера, чтобы делать запрос за данными на каждое открытие
- `onSelect` - обработчик выбора элемента (автоматически открывает ссылку)

### useSupportProps

Хук встроен в `Header` и автоматически отправляет форму поддержки через API:

**Endpoint:** `POST /api/send-support-email/`

**Отправляемые данные:**

- `module` - выбранный модуль
- `criticality` - критичность проблемы
- `title` - заголовок обращения
- `description` - описание проблемы (опционально)
- `fio` - ФИО пользователя
- `role` - роль пользователя
- `email` - email пользователя
- `phone` - телефон (опционально)
- `files` - прикрепленные файлы (опционально)

**Content-Type:** `multipart/form-data`

### Ручная настройка

Header использует эти хуки, если вы передали адреса для API в `burger` и `support`.

Пользовательские настройки имеют приоритет над данными, полученными из API.

Вы можете настроить API конфигурацию для burger и support:

```tsx
import { useMemo } from 'react';
import { Header, HeaderProps } from '@rovna-ui/header';

const Component = () => {
  const headerProps: HeaderProps = useMemo(
    () => ({
      burger: {
        api: {
          cache: { key: 'rovna-ui-global-services', cacheTime: 60_000, staleTime: 0 },
          url: '/api/product_b2b/',
        },
        // Дополнительные настройки burger
      },
      support: {
        moduleOptionsApi: {
          cache: { key: 'rovna-ui-global-services', cacheTime: 60_000, staleTime: 0 },
          url: '/api/product_b2b/',
        },
        // Дополнительные настройки support
      },
    }),
    [],
  );

  return <Header {...headerProps} />;
};
```

**Примечание:**

- API должно быть [настроено](/bu_moscow/10d/common/django-saas-lib) на стороне бэкенда для корректной работы интеграции. Если API недоступно, `Header` будет работать с переданными вручную данными.
- Также должен быть [переопределен](/?path=/docs/tend-ui-main-tendui--docs#переопределение-клиента-для-защищенных-url) стандартный `axios` клиент, чтобы `RovnaUI` мог делать запросы для защищенных адресов.
