# useSupportModal

Хук для глобального управления модалкой поддержки. Использует Singleton паттерн для обеспечения единого состояния модалки во всем приложении.

## Описание

`useSupportModal` предоставляет глобальное состояние для модалки поддержки, позволяя открывать и закрывать её из любого места в приложении. Хук использует внутреннее глобальное состояние и систему подписок для синхронизации всех компонентов, использующих этот хук.

## Использование

```tsx
import { useSupportModal } from '@rovna-ui/header';

const MyComponent = () => {
  const { isOpen, openSupport, closeSupport, toggleSupport } = useSupportModal();

  return (
    <div>
      <p>Статус модалки: {isOpen ? 'Открыта' : 'Закрыта'}</p>
      <button onClick={openSupport}>Открыть поддержку</button>
      <button onClick={closeSupport}>Закрыть поддержку</button>
      <button onClick={toggleSupport}>Переключить</button>
    </div>
  );
};
```

## Примеры

### Базовое использование

```tsx
const SupportButton = () => {
  const { openSupport } = useSupportModal();

  return <button onClick={openSupport}>Нужна помощь?</button>;
};
```

### Переключение состояния

```tsx
const SupportToggle = () => {
  const { isOpen, toggleSupport } = useSupportModal();

  return (
    <button onClick={toggleSupport}>
      {isOpen ? 'Закрыть поддержку' : 'Открыть поддержку'}
    </button>
  );
};
```

### Условное отображение

```tsx
const SupportStatus = () => {
  const { isOpen, closeSupport } = useSupportModal();

  if (!isOpen) return null;

  return (
    <div className='support-indicator'>
      <span>Модалка поддержки открыта</span>
      <button onClick={closeSupport}>×</button>
    </div>
  );
};
```

## Особенности

- **Глобальное состояние**: Все компоненты, использующие хук, синхронизируются автоматически
- **Singleton паттерн**: Гарантирует единое состояние для всего приложения
- **Оптимизация**: Минимальные ререндеры благодаря системе подписок
- **Простота использования**: Нет необходимости в провайдерах или контексте

## Примечания

- Предполагается, что модалка поддержки одна на странице
- Хук автоматически очищает подписки при размонтировании компонента
- Состояние сбрасывается при обновлении страницы
