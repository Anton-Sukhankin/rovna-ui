# Иконки

> Иконки переехали в отдельный пакет `@rovna-ui/icons` и все новые иконки будут поставляться им. Все ныне добавленные иконки в пакете `@rovna-ui/components` будут также поддерживаться, но новых появляться не будет

## Использование

```tsx
import { Help, Error, AccountBox } from '@rovna-ui/icons';

<Help  />
<Error />
<AccountBox color='red' />
<AccountBox size={64} />
```

### Для лучшего `tree-shaking`

```tsx
import { Help } from '@rovna-ui/icons/Help';
import { Error } from '@rovna-ui/icons/Error';
import { AccountBox } from '@rovna-ui/icons/AccountBox';

<Help />
<Error />
<AccountBox color='red' />
<AccountBox size={64} />
```

### Начиная с версии `4.2.0`

```tsx
import { Error, AccountBox } from '@rovna-ui/icons';

<Error color='blue100' />
<AccountBox color='blue50-transparent' />
```

Чтобы скопировать `sourcecode` кликни на нужную иконку

<IconGallery>
  <RovnaUI>
    {Object.values(Icons).map(Icon => {
      const isDeprecated = !!Icon.__DEPRECATED;
      const name = isDeprecated
        ? `${Icon.displayName} (deprecated, use ${Icon.__DEPRECATED})`
        : Icon.displayName;
      return (
        <IconItem name={name}>
          <span style={{ background: isDeprecated && '#FF7F7F' }}>
            <Icon
              onClick={() => {
                const sourceCode = `<${Icon.displayName} />`;
                navigator.clipboard.writeText(sourceCode).then(() => {
                  message.success(`Скопировано в буфер обмена ${sourceCode}`);
                });
              }}
            />
          </span>
        </IconItem>
      );
    })}
  </RovnaUI>
</IconGallery>
