# Логотипы

## Использование

```tsx
import { SHome, SFine, SBlueprint } from '@rovna-ui/logos';

<SHome />
<SFine />
<SBlueprint />
<SBlueprint size={64} />
```

### Для лучшего `tree-shaking`

```tsx
import { SHome } from '@rovna-ui/logos/SHome';
import { SFine } from '@rovna-ui/logos/SFine';
import { SBlueprint } from '@rovna-ui/logos/SBlueprint';

<SHome />
<SFine />
<SBlueprint />
<SBlueprint size={64} />
```

Чтобы скопировать `sourcecode` кликни на нужный логотип

<IconGallery>
  {Object.values(Icons).map(Icon => {
    const isDeprecated = !!Icon.__DEPRECATED;
    const name = isDeprecated
      ? `${Icon.displayName} (deprecated, use ${Icon.__DEPRECATED})`
      : Icon.displayName;
    return (
      <IconItem name={name}>
        <Icon
          onClick={() => {
            const sourceCode = `<${Icon.displayName} />`;
            navigator.clipboard.writeText(sourceCode).then(() => {
              message.success(`Скопировано в буфер обмена ${sourceCode}`);
            });
          }}
        />
      </IconItem>
    );
  })}
</IconGallery>
