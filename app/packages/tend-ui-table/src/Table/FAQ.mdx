# FAQ

### Почему таблица состоит из кучи `boilerplate` кода? Я хочу просто импортировать все одной строчкой и все

Такой подход был выбран целенаправлено. Таблица - модульный компонент. Благодаря паттерну `compound components` разработчик может гибко включать/исключать нужные/ненужные части таблицы. Также, благодаря этому подходу, появляется возможность "дружить" модули таблицы с любой другой (`@tanstack/react-table`)

### Я использулью фильтр типа `async-select`. При открытии `select` в выпадающем меню в заголовке таблицы данные загружаются, но при повторном открытии этого же фильтра в боковом меню фильтров `select` загружает те же самые данные еще раз. Что делать?

У фильтра типа `async-select` есть настройка `cache`. Задайте уникальный ключ и при повторном открытии `select` данные загрузятся из кеша моментально.

> Важно! Кеш - глобальное хранилище, доступное для всех компонентов `AsyncSelect` вне зависимости от того где они находятся оносительно друг друга. Два `AsyncSelect` с одинаковым ключем на разных страницах также будут "шерить" кешированные данные

```tsx
const filter: Table.FilterConfig = {
  key: 'contractor',
  id: 'contractor',
  name: 'contractor',
  label: 'Подрядчик',
  component: {
    component: 'async-select',
    placeholder: 'Выберите подрядчика',
    api: {
      cache: {
        key: 'unique-contractor-cache-id', // уникальный для конкретного url/callback
      },
      url: '/api/contractos/',
    },
  },
};
```

### Я прокидываю кастомный контент в ячейки таблицы в заголовках с помощью свойства `title`, но при этом этот же кастомный контент появляется в списке в боковом меню фильтров. Что делать?

Используйте дополнительно свойство `label` в конфиге настроек колонок. Оно имеет более высокий приоритет

```tsx
const column: Table.ColumnType = {
  label: 'Подрядчик',
};
```

### У меня не работает закрепление (`pinning`) колонок. Что делать?

Возможно, вы забыли передать свойство `scroll` компоненту `Table.Table`

```tsx
<Table.Table scroll={{ x: 1300 }} /> // наличие свойства обязательно для корректной работы
```

### У меня есть колонка, которую я не хочу отображать в боковом меню фильтров. Что делать?

Используйте свойство `ignore` у хука `useColums()`.

```tsx
const [tableColumns] = Table.useColumns({
  ignore: ['contractor'], // id колонок, которые не нужно отображать в настройках
  columns: [...]
})
```

### Я передал `filters` в компонент `Table.Root`, обернул заголовки таблицы `Table.ContextMenu`, но в выпадающем меню не отображается фильтр. Что делать?

Проверьте правильность конфигурации колонки.

```tsx
const column: Table.ColumnType = {
  key: 'column-number',
  id: 'number', // уникальный id должен совпадать
  title: 'Номер',
  dataIndex: 'number',
  onHeaderCell: () => ({
    id: 'number', // уникальный id должен совпадать
  }),
};

const filter: Table.FilterConfig = {
  key: 'filter-number',
  id: 'number', // уникальный id должен совпадать
  name: 'number',
  label: 'Номер',
  component: { component: 'input', placeholder: 'Введите номер' },
};
```

### Мне нужно чтобы один фильтр был недоступен для выбора пока не выбран другой. Что делать?

Используйте свойство `requires`

```tsx
const filter: Table.FilterConfig[] = [
  {
    key: 'filter-number',
    id: 'number',
    name: 'number',
    label: 'Номер',
    component: { component: 'input', placeholder: 'Введите номер' },
  },
  {
    key: 'filter-contractor',
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    requires: ['number'], // Массив name фильтров, от которых есть зависимость
    component: { component: 'input', placeholder: 'Введите подрядчика' },
  },
];
```

### Мне нужно при выборе значений в одном фильтре зависящий от него фильтр семейства `async-*` делал запрос с выбранными значениями. Что делать?

Используйте свойство `depends`

```tsx
const filter: Table.FilterConfig[] = [
  {
    key: 'filter-number',
    id: 'number',
    name: 'number',
    label: 'Номер',
    component: { component: 'input', placeholder: 'Введите номер' },
  },
  {
    key: 'filter-contractor',
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    depends: ['number'], // Массив name фильтров, от которых есть зависимость
    component: { component: 'async-select', api: '/api/example/' },
  },
];
```

### Я скрыл колонку через выпадающее меню в заголовке таблицы. Как вернуть колонку назад?

Вернуть колонку можно только через боковое меню настроек колонок
