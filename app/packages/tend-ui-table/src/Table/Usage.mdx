# Использование

1. Таблица экспортируется из пакета `@rovna-ui/table` под `namespace`, к этому `namespace` прицепляются различные компоненты, интерфейсы и хуки. Импортируем его

```tsx
import { Table } from '@rovna-ui/table';
```

2. Настройка колонок поставляется отдельной библиотекой, экспортируем все необходимое.

```tsx
import { useColumns, DrawerColumnsSettings } from '@rovna-ui/columns-settings';
import { Table } from '@rovna-ui/table';
```

3. Собираем начальный шаблон компонента

```tsx
import { useColumns, DrawerColumnsSettings } from '@rovna-ui/columns-settings';
import { Table } from '@rovna-ui/table';

const Page = () => {
  return (
    <Table.Root>
      <Table.Header>
        <Table.ControlPanel />
        <Table.Search />
        <Table.HotFilters />
      </Table.Header>
      <Table.Table />
      <DrawerColumnsSettings />
    </Table.Root>
  );
};
```

Самой таблицы как компонента **не существует**. Таблица - это набор готовых компонентов, которые взаимодействует между собой через `React Context`. Сделано это для того, чтобы не создавать сотню свойство вида `showFilters`, `showControlPanel`, `showColumnsSettings` и так далее. Библиотека просто предоставляет инструменты для построения таблицы, а продуктовые команды сами решает какие части им нужны, а какие нет. Другие причины этого подхода мы будем рассматривать по ходу данного примера

4. Далее, подключаем к `Table.Root` настройку колонок

```tsx
const columns: Table.ColumnType[] = [
  {
    // Это свойство должно полностью совпадать со свойством в onHeaderCell
    id: 'contractor',
    label: 'Подрядчик',
    title: 'Подрядчик',
    onHeaderCell: () => ({
      // Это свойство должно полностью совпадать со свойством id
      id: 'contractor',
    }),
  },
];

import { useColumns, DrawerColumnsSettings } from '@rovna-ui/columns-settings';
import { Table } from '@rovna-ui/table';

const Page = () => {
  const settings = useColumns({ defaultColumns: columns });

  return (
    <Table.Root settings={settings}>
      <Table.Header>
        <Table.ControlPanel
          settingsButtonProps={{
            onClick: function () {
              // Логика открытия/закрытия DrawerColumnsSettings
            },
          }}
        />
        <Table.Search />
        <Table.HotFilters />
      </Table.Header>
      <Table.Table columns={settings.getAntdTableColumns()} />
      <DrawerColumnsSettings
        open={true}
        onClose={() => {
          // логика при закрытии
        }}
        settings={settings}
      />
    </Table.Root>
  );
};
```

В нашем примере мы вызвали основной хук для работы с колонками `useColumns` из пакета `@rovna-ui/columns-settings`. Все, что связано с настройкой колонок, происходит через этот `hook`. Передав модель, которую возвращает `hook` в `Table.Root` мы "подружили" таблицу с функционалом настройки колонок. Под капотом `Table.Root` будет использовать методы, предоставляемые `useColumns`.

Не забудьте передать модель `settings` в `DrawerColumnsSettings` а также обратите внимание, что логику по открытию/закрытию `DrawerColumnsSettings` вам нужно написать самим

5. Теперь давайте посмотрим на пример того, как подключать фильтры.

Чтобы фильтры заработали, достаточно просто передать конфигурацию в `Table.Root`

```tsx
import { useColumns, DrawerColumnsSettings } from '@rovna-ui/columns-settings';
import { Table } from '@rovna-ui/table';

const columns: Table.ColumnType[] = [
  {
    // Это свойство должно полностью совпадать со свойством в onHeaderCell
    id: 'contractor',
    label: 'Подрядчик',
    title: 'Подрядчик',
    onHeaderCell: () => ({
      // Это свойство должно полностью совпадать со свойством id
      id: 'contractor',
    }),
  },
];

// Типизируем конфигурацию с помощью интерфейса из namespace Table
const filters: Table.FilterConfig[] = [
  {
    key: 'contractor',
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    component: { component: 'input', placeholder: 'Подрядчик' },
  },
  {
    key: 'provider',
    id: 'provider',
    name: 'provider',
    label: 'Поставщик',
    component: { component: 'input', placeholder: 'Поставщик' },
  },
];

const Page = () => {
  const settings = useColumns({ defaultColumns: columns });

  return (
    // Передаем нашу конфигурацию в Table.Root
    <Table.Root settings={settings} filters={filters}>
      <Table.Header>
        <Table.ControlPanel
          filtersButtonProps={{
            onClick: function () {
              // Логика открытия/закрытия фильтров
            },
          }}
        />
        <Table.Search />
        <Table.HotFilters />
      </Table.Header>
      <Table.Table columns={settings.getAntdTableColumns()} />
      {/* Вставляем компонент фильтров из namespace Table */}
      <Table.Filters open={true} />
      <DrawerColumnsSettings
        open={true}
        onClose={() => {
          // логика при закрытии
        }}
        settings={settings}
      />
    </Table.Root>
  );
};
```

Готово. Мы подключили фильтры к нашему шаблону. Все необходимые `callback` для получения значений фильтров находятся в `Table.Root`. Обратите внимание, что логику по открытию/закрытию `Filters` вам нужно написать самим

```tsx
<Table.Root onFilterValuesChange={...}>
...
</Table.Root>
```

6. Чтобы подключить в таблицу выпадающее контекстное меню в заголовках таблицы необходимо сделать следующее

> Важно! Во всех проектах самолета используется таблица `Table` из библиотеки `antd`. Чтобы добиться функционала выпадающего меню используется свойство `components` таблицы `Table` из `antd`. С помощью него мы просто "пробрасываем" внутрь таблицы необходимый нам функционал

```tsx
import { useColumns, DrawerColumnsSettings } from '@rovna-ui/columns-settings';
import { Table } from '@rovna-ui/table';

const columns: Table.ColumnType[] = [
  {
    // Это свойство должно полностью совпадать со свойством в onHeaderCell
    id: 'contractor',
    label: 'Подрядчик',
    title: 'Подрядчик',
    onHeaderCell: () => ({
      // Это свойство должно полностью совпадать со свойством id
      id: 'contractor',
    }),
  },
];

const filters: Table.FilterConfig[] = [
  {
    key: 'contractor',
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    component: { component: 'input', placeholder: 'Подрядчик' },
  },
  {
    key: 'provider',
    id: 'provider',
    name: 'provider',
    label: 'Поставщик',
    component: { component: 'input', placeholder: 'Поставщик' },
  },
];

const Page = () => {
  const settings = useColumns({defaultColumns: columns});

  return (
    <Table.Root settings={settings} filters={filters}>
      <Table.Header>
        <Table.ControlPanel />
        <Table.Search />
        <Table.HotFilters />
      </Table.Header>
      <Table.Table
        columns={settings.getAntdTableColumns()}
        components={{
          {/* Кастомизируем заголовки таблицы antd с помощью нашего компонента */}
          header: {
            cell: (props: React.HTMLAttributes<HTMLTableCellElement>) => (
              {/* Подключаем компонент Table.ContextMenu */}
              {/* Прокидываем в него id. Этот id тот же самый id что используется в columns */}
              <Table.ContextMenu id={props.id}>
              {/* Возвращаем все свойства antd */}
                <Table.HeaderCell {...props} />
              </Table.ContextMenu>
            ),
          },
        }}
      />
      <Table.Filters open={true} />
      <DrawerColumnsSettings
        open={true}
        onClose={() => {
          // логика при закрытии
        }}
        settings={settings}
      />
    </Table.Root>
  );
};
```

Готово. Теперь нам доступно контекстное меню, которое можно открыть кликнув на заголовок таблицы

> Важно! Обратите внимание, что поле `id` в `filters`, `columns` и `sorters` - сквозное. С помощью этого свойства компоненты таблицы понимают где и что нужно отображать. Для колонки с `id: "contractor"` будет отображен фильтр с `id: "contractor"`

7. Похожим образом подключается конфигурация сортировки

```tsx
import { useColumns, DrawerColumnsSettings } from '@rovna-ui/columns-settings';
import { Table } from '@rovna-ui/table';

const sorters: Table.SorterConfig[] = [
  {
    // Это свойство должно полностью совпадать со свойством id из columns и filters для одной колонки
    id: 'contractor',
    name: 'contractor',
  },
];

const columns: Table.ColumnType[] = [
  {
    // Это свойство должно полностью совпадать со свойством в onHeaderCell
    id: 'contractor',
    label: 'Подрядчик',
    title: 'Подрядчик',
    onHeaderCell: () => ({
      // Это свойство должно полностью совпадать со свойством id
      id: 'contractor',
    }),
  },
];

const filters: Table.FilterConfig[] = [
  {
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    component: { component: 'input', placeholder: 'Подрядчик' },
  },
  {
    id: 'provider',
    name: 'provider',
    label: 'Поставщик',
    component: { component: 'input', placeholder: 'Поставщик' },
  },
];

const Page = () => {
  const settings = useColumns({defaultColumns: columns});

  return (
    {/* Прокидываем конфигурацию sorters в Table.Root */}
    <Table.Root settings={settings} filters={filters} sorters={sorters}>
      <Table.Header>
        {/* Компонент подхватит конфигурацию sorters автоматически */}
        {/* Компонент подхватит конфигурацию sorters автоматически */}
        <Table.ControlPanel
          filtersButtonProps={{
            onClick: function () {
              // Логика открытия/закрытия фильтров
            }
          }}
        />
        <Table.Search />
        <Table.HotFilters />
      </Table.Header>
      <Table.Table
        columns={settings.getAntdTableColumns()}
        components={{
          header: {
            cell: (props: React.HTMLAttributes<HTMLTableCellElement>) => (
              <Table.ContextMenu id={props.id}>
                <Table.HeaderCell {...props} />
              </Table.ContextMenu>
            ),
          },
        }}
      />
      <Table.Filters open={true} />
      <DrawerColumnsSettings
        open={true}
        onClose={function () {
          // логика при закрытии
        }}
        settings={settings}
      />
    </Table.Root>
  );
};
```

Это базовый пример того, как можно использовать библиотеку `@rovna-ui/table`.

В дальнейшем планируется уйти от `context` в сторону `headless` подхода, сделать использование еще гибче и получить примерно следующее `api`:

```tsx
import { Table } from '@rovna-ui/components/primitives';
import { useTable, ContextMenu } from '@rovna-ui/table';
import { Filters } from '@rovna-ui/filters';
import { DrawerColumnsSettings, useColumns } from '@rovna-ui/columns-settings';

const Page = () => {
  const settings = useColumns();
  const table = useTable({
    settings,
    filters: [],
    sorters: [],
    onFilterValuesChange: function () {},
    onSortersValuesChange: function () {},
  });

  return (
    <div>
      <Table {...table.registerAntdTable()} />
      <Filters {...table.registerFilters()} />
      <DrawerColumnsSettings settings={settings} />
    </div>
  );
};
```
