# useRowHighlighter

## Использование

```tsx
import { Table } from '@rovna-ui/table';

const rowClassName = Table.useRowHighlighter({
  onSuccess: record => record.price > 500,
});

<Table.Table rowClassName={rowClassName} />;
```
