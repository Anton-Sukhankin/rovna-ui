# Интерфейсы

## Table.ColumnType

Интерфейс колонок таблицы из `antd` + все свойства `Table.ColumnConfig`. При использовании сторонней библиотеки таблиц рекомендуется использовать `Table.ColumnConfig`

> Важно! `id` - уникальный связывающий идентификатор. Это сквозное свойство между сущностями `Table.ColumnType`, `Table.FilterConfig`, `Table.SorterConfig`, `Table.CellTitle`

### Пример

```tsx
import { Table } from '@rovna-ui/table';

const _columns: Table.ColumnType[] = [
  {
    id: 'contractor',
    title: <Table.CellTitle id='contractor'>Подрядчик</Table.CellTitle>,
    /**
     * Обязательно добавить это свойство для однозначного связывания колонки с компонентом Table.ContextMenu
     */
    onHeaderCell: () => ({
      id: 'contractor',
    }),
  },
];
```

### Table.FilterConfig

Интерфейс фильтров таблицы. [Подробнее](/?path=/docs/components-filters--docs)

> Важно! `id` - уникальный связывающий идентификатор. Это сквозное свойство между сущностями `Table.ColumnType`, `Table.FilterConfig`, `Table.SorterConfig`, `Table.CellTitle`

```tsx
import { Table } from '@rovna-ui/table';

const filters: Table.FilterConfig[] = [
  {
    key: 'filter-contractor',
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    component: { component: 'input', placeholder: 'Введите имя подрядчика' },
  },
];
```

### Table.SorterConfig

Интерфейс сортировки таблицы.

```tsx
import { Table } from '@rovna-ui/table';

const sorters: Table.SorterConfig[] = [
  {
    key: 'sorter-contractor',
    id: 'contractor',
    name: 'contractor',
    label: 'Подрядчик',
    disabled: false,
  },
];
```
