# extract

## Использование

```tsx
import { extract } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { extract } from '@rovna-ui/utils/extract';
```

```js
console.log(extract({ a: { b: 'Hello Wolrd' } }), ['a', 'b']); // Hello World
console.log(extract({ a: { b: 'Hello Wolrd' } }), ['a', 'b', 'c']); // "undefined"
```
