# isExceed

## Использование

```tsx
import { isExceed } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { isExceed } from '@rovna-ui/utils/isExceed';
```

```js
isExceed(75, 100, 80); // false
isExceed(80, 100, 80); // true
```
