# keys

## Использование

```tsx
import { keys } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { keys } from '@rovna-ui/utils/keys';
```

```js
keys({ a: 1, b: 2, c: 3 }); // ['a', 'b', 'c']
```
