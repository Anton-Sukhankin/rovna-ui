# swap

## Использование

```tsx
import { swap } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { swap } from '@rovna-ui/utils/swap';
```

```js
console.log(swap(['a', 'b', 'c'], 0, 0)); // ['a', 'b', 'c']
console.log(swap(['a', 'b', 'c'], -1, 0)); // ['a', 'b', 'c']
console.log(swap(['a', 'b', 'c'], 0, -1)); // ['a', 'b', 'c']
console.log(swap(['a', 'b', 'c'], -1, -1)); // ['a', 'b', 'c']

console.log(swap(['a', 'b', 'c'], 0, 2)); // ['c', 'b', 'a']
console.log(swap(['a', 'b', 'c'], 1, 0)); // ['b', 'a', 'c']
```
