# key

## Использование

```tsx
import { key } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { key } from '@rovna-ui/utils/key';
```

```js
const obj = { a: 1, b: 2, c: 3, d: 'Hello World' };

key(obj, 1); // 'a'
key(obj, 2); // 'b'
key(obj, 3); // 'c'
key(obj, 'Hello World'); // 'd'
```
