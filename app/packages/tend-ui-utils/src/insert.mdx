# insert

## Использование

```tsx
import { insert } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { insert } from '@rovna-ui/utils/insert';
```

```js
insert(['1', '2', '3'], '4', value => value === '2'); // ['1', '2', '4', '3']
```
