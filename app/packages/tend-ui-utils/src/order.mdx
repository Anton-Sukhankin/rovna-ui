# order

## Использование

```tsx
import { order } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { order } from '@rovna-ui/utils/order';
```

```js
console.log(order([{ id: 'a' }, { id: 'b' }, { id: 'c' }], ['b', 'a', 'c'], 'id')); // [{id: 'b'}, {id: 'a'}, {id: 'c'}]
```
