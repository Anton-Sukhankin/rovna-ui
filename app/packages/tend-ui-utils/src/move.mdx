# move

## Использование

```tsx
import { move } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { move } from '@rovna-ui/utils/move';
```

```js
console.log(move(['a', 'b', 'c', 'd'], 0, 0)); // ['a', 'b', 'c', 'd']
console.log(move(['a', 'b', 'c', 'd'], -1, 0)); // ['a', 'b', 'c', 'd']
console.log(move(['a', 'b', 'c', 'd'], 0, -1)); // ['a', 'b', 'c', 'd']
console.log(move(['a', 'b', 'c', 'd'], -1, -1)); // ['a', 'b', 'c', 'd']

console.log(move(['a', 'b', 'c', 'd'], 3, 0)); // ['d', 'a', 'b', 'c']
```
