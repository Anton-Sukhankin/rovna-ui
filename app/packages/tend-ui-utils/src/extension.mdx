# extension

## Использование

```tsx
import { extension } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { extension } from '@rovna-ui/utils/extension';
```

```js
extension('helloworld.txt'); // ''.txt'
extension('HelloWorld.pdf'); // '.pdf'
extension('hElOwOrLd.avi'); // '.avi'
extension('h_e_l_o_w_o_r_l_d.mp3'); // '.mp3'
extension('hello.world.docx'); // '.docx'
extension('helloworld'); // null
```
