# name

## Использование

```tsx
import { name } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { name } from '@rovna-ui/utils/name';
```

```js
name('helloworld.txt'); // "helloworld"
name('HelloWorld.pdf'); // "HelloWorld"
name('hElOwOrLd.avi'); // "hElOwOrLd"
name('h_e_l_o_w_o_r_l_d.mp3'); // "h_e_l_o_w_o_r_l_d"
name('hello.world.docx'); // "hello.world"
name('helloworld'); // "helloworld"
name(''); // ''
```
