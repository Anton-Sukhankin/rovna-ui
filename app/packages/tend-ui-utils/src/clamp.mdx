# clamp

## Использование

```tsx
import { clamp } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { clamp } from '@rovna-ui/utils/clamp';
```

```js
clamp(0, 1, 5); // 1
clamp(2, 1, 5); // 2
clamp(6, 1, 5); // 6
```
