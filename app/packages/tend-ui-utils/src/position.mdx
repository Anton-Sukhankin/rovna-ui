# position

## Использование

```tsx
import { position } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { position } from '@rovna-ui/utils/position';
```

```js
position(['1', '2', '3'], '4', 0); // ['4', '1', '2', '3']
```
