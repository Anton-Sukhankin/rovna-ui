# formatBytes

## Использование

```tsx
import { formatBytes } from '@rovna-ui/utils';
```

### Для лучшего `tree-shaking`

```tsx
import { formatBytes } from '@rovna-ui/utils/formatBytes';
```

```js
formatBytes(454912); // 455 kb
formatBytes(3859123); // 3.9 MB
```
