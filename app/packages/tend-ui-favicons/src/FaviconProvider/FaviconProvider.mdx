# FaviconProvider

Компонент для управления favicon в приложении. Позволяет динамически изменять favicon в зависимости от типа сервиса.

## Описание

`FaviconProvider` - это React компонент, который автоматически устанавливает соответствующий favicon для различных сервисов 10D. Компонент использует CDN для загрузки favicon файлов и React Helmet для управления мета-тегами.

## Использование

```tsx
import { FaviconProvider } from '@rovna-ui/favicons';

function App() {
  return (
    <>
      <FaviconProvider type='pass-10D' />
      {/* Остальное содержимое приложения */}
    </>
  );
}
```

## Соответствие сервисов и фавиконок

### Global продукты

- **LK**: `lk-10D`
- **SBlueprint**: `sod-10D`
- **SCenter**: `reports-10D`
- **SControl**: `quality-10D`
- **SGantt**: `plan-10D`
- **SKek**: `ks-manager-10D`
- **SMaterials**: `materials-10D`
- **SPass**: `pass-10D`
- **SPass-Report**: `pass-gdrs-10D`
- **SPro**: `pro-10D`
- **SRMP**: `rmp-10D`
- **STender**: `tender-10D`

### Samolet продукты

- **LK**: `undefined`
- **SBlueprint**: `sblueprint`
- **SMaterials**: `smaterials`
- **Остальные сервисы**: `?` (не определены)

## Генерируемые форматы

Компонент автоматически генерирует следующие форматы favicon:

- **SVG** - для современных браузеров
- **ICO** - для старых браузеров и IE
- **PNG 16x16** - для маленьких иконок
- **PNG 32x32** - стандартный размер
- **PNG 48x48** - для больших иконок
- **Apple Touch 180x180** - для iOS устройств

## Генерируемый HTML код

Компонент автоматически вставляет следующий HTML код в `<head>` секцию:

```html
<link
  rel="icon"
  type="image/svg+xml"
  href="/favicons/{type}.svg"
/>
<link
  rel="icon"
  type="image/x-icon"
  href="/favicons/{type}.ico"
/>
<link
  rel="icon"
  type="image/png"
  sizes="16x16"
  href="/favicons/{type}-16.png"
/>
<link
  rel="icon"
  type="image/png"
  sizes="32x32"
  href="/favicons/{type}-32.png"
/>
<link
  rel="icon"
  type="image/png"
  sizes="48x48"
  href="/favicons/{type}-48.png"
/>
<link
  rel="apple-touch-icon"
  sizes="180x180"
  href="/favicons/{type}-apple-touch.png"
/>
<link rel="shortcut icon" href="/favicons/{type}.ico" />
```
